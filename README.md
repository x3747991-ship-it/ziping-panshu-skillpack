# 盘叔子平 · 子平命学融会贯通最强技能包

> **十经融贯 · 一宗正法。** 把《子平真诠》《渊海子平》《滴天髓》《穷通宝鉴》《三命通会》《神峰通考》《命理约言》《命理探原》《千里命稿》《命谱》十部子平经典的蒸馏技能包，融合为一个统一体系：格局（真诠）、理气（滴天髓）、调候（穷通）、源头（渊海）、百科（三命）、病药（神峰）、仲裁（约言）、折中（探原）、实务（千里）、标尺（命谱），各安其位，三用神并行，主从裁决。

## 一、核心定位

- **输入**：四柱（年 / 月 / 日 / 时柱干支）+ 性别；未给具体公历生年默认「最近 50 年生人」定位。
- **输出**：原局定局断事 + 结合行运逐运断吉凶，两大块缺一不可。
- **三用神统一**：格局用神 / 调候用神 / 扶抑用神，三栏对照 + 主从裁决。
- **流派分歧双说并陈**：不伪造唯一答案，每条断语可追溯出处。

## 三、使用方法

1. 将整个 `盘叔子平/` 目录作为技能包挂载到 TRAE / 你的 AI 助手中。
2. 用户报出「四柱 + 性别」，从总纲 `SKILL.md` 入手，按八步全流程调度。
3. 只问单一专题时，直接分流域对应子技能，不做全流程重算。

## 四、方法共识

- 本包为**子平法**（以日干立极、月令取格），与禄命法（年柱纳音）是两套体系，不混用。
- 神煞、纳音只作取象辅助，不独立成断。
