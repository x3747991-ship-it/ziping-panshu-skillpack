# M5 校验库 · 《命谱》六十四造回归基准

> 数据源：《命谱》六十四造详解（袁树珊）——每造含「八字 + 命谱格局名 + 取用方向」。
> 用途：对「盘叔子平」做格局定名 / 用神识别 / 层次评估三类回归校验。校验状态 `✅`=盘叔子平体系可复现；`⚠️`=需双说并陈（流派分歧）；`❌`=需修订规则。

## 格局归类口径（映射到盘叔子平四类）

| 盘叔子平归类 | 解释 | 路由子技能 |
|---------|------|-----------|
| 化气格 | 天干五合成化，袁氏化气本位 | `ziping-huacong` |
| 专旺格 | 日主旺极成一气/方局（曲直、润下等） | `ziping-zhuanwang` |
| 从格 | 从财/从杀/从儿 | `ziping-huacong` |
| 专名格 | 命谱历史命名（三奇、连珠、拱贵…），盘叔子平降格为「正格+取象/神煞点缀」 | `ziping-zhengge` + 神煞 |
| 正格 | 月令定格（真诠主轴） | `ziping-zhengge` + 对应十神格 |
