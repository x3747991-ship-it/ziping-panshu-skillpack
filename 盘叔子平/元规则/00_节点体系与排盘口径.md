## 二、排盘定标标准（十书统一输入，杜绝"各排各的"）

### 2.1 输入端（问命必须齐备）
```
四柱（年柱/月柱/日柱/时柱 干支）+ 性别
```
- **公历生年缺省规则**：四柱已含年柱（干支），但问命者未注明具体公历生年（位于哪一轮甲子）时，**统一默认「最近 50 年生人」**——按该年柱在近一个甲子内最近一次出现的公历年份定位，用于定立春节气、折算起运、排大运流年；若实为更早生人（跨甲子），待问命者补出生年后重新定位。
- 出生地（真太阳时换算）与出生日期（节气核对）为**可选补充项**：缺省时按标准北京时间、不经真太阳时修正排盘；涉及节气临界、越时区等须精确定界的盘，补出生地后复核。
- 时辰不确定的盘：时柱相关判断（位置先后、透清、时支喜用、归禄等）全部降级为"待定时辰复核"，**不得**硬断。
- 输入边界（十书共识，一律不接）：紫微斗数、手相、六爻、姓名、仅生肖年份、排盘方法论本身。

### 2.2 立极与节气
- **以日干立极**（渊海子平）：一切强弱、十神、喜忌以日干为原点换算；**不采年柱纳音立极**。
- 月令以**节气**定（立春建寅），非农历初一；真太阳时折算后取节气交接时刻前后者，须标注"交节临界"。
- **藏干不依人元司令分野分日用事**（命理约言明言"各干分日万不可拘"），以月支本气为主、余气兼取；与依分野取格的旧法冲突时，从约言口径并在结论处标注。

### 2.3 大运 / 小运 / 命宫 / 胎元 / 纳音
- 起运：阳男阴女顺行、阴男阳女逆行；折除三日为一岁（三命通会）。
- 大运重支、干支兼论；十年一辰、上下五年分野、男迎女送（三命通会 + 命理探原）。
- 命宫与胎元：命宫重于胎元（命谱）；纳音随四柱起（三命通会、命谱供纳音，但**纳音不独立成断**，见元规则 03）。

### 2.4 神煞表
- 神煞由三命通会 + 渊海子平供给，**只在 L8 断事时作取象辅助，不构成独立断法、不救破格、不损成格**（真诠/滴天髓/约言的共同立场，铁律见元规则 03）。

### 2.5 论命硬约定（原局 + 行运两步必做）
- 每个八字默认出**两大块，缺一不可**：
  1. **原局定局断事**（L0–L8）：排盘 → 辨体（特殊格/身强弱）→ 取格 → 三用神统一 → 富贵/六亲/婚姻/事业/健康；
  2. **结合行运分析**（L7 岁运，`ziping-suiyun`）：以原局用神喜忌为唯一标尺，逐大运定吉凶朝向、逐流年观动静引动，圈交运/并临/伏吟反吟高危窗口定应期。
- **行运是整体论命的默认必做环节**，不是"只问哪年发财/有灾才走"。单一应期追问才单独分流域 `ziping-suiyun`；做完整论命时不得跳过行运块。
