# 元规则 02 · 三用神统一与主从裁决

> 这是「盘叔子平」融合的灵魂机制。十部书对"用神"有六种定义（见元规则 01），强行只取一个会系统性漏判。本包的做法是：**同一八字，并行开三个视角取用，再按固定主从顺序裁决**，输出一个"三视角合流 + 分歧标注"的完整结论。

## 一、三用神定义（并行取用，互不替代）

| 视角 | 名称 | 回答的问题 | 供给书 | 产出 |
|------|------|-----------|--------|------|
| ① 格局用神 | 月令定格之神 | 这个八字是什么格、档次如何 | 子平真诠（主轴）+ 千里八格 + 约言取格链 | 格局定名 + 成破 + 层次 |
| ② 调候用神 | 寒暖燥湿补偏之字 | 冬夏生人缺什么气、格局喜忌是否要因调候转弯 | 穷通宝鉴（十干十二月）+ 滴天髓寒暖燥湿 | 调候补偏字 + 是否"调候为急" |
| ③ 扶抑用神 | 抑强扶弱之字 | 日主强弱、该扶该抑、通关为何 | 滴天髓 + 千里命稿 + 神峰病药 | 身强弱判定 + 喜忌 + 药 |

## 二、取用三步流程（总纲调度，子技能各领一段）

```
第一步  辨体（L1）：判特殊格 → 定身强弱
        1a 先判化气 / 从格 / 专旺（曲直炎上稼穑从革润下）
            依据：命谱化气真假 + 滴天髓从象化象 + 约言变格六种 + 穷通变格
            → 成立则跳过正格，直接用该格自身喜忌论命（此时三者合一）
        1b 不成立 → 定身强弱（千里"身强身弱" + 滴天髓"得令得地得生得助"四维）

第二步  定局（L2）：取格局用神 ①
        按取格降级链定名（子平真诠格局法为主轴，千里/约言取格链印证）
        顺用逆用：财官印食善神顺用（生护），杀伤刃凶神逆用（制化）
        查成败救应、相神、清浊 → 定格局层次

第三步  修正校验（L3）：叠调候用神 ② → 校扶抑用神 ③
        ② 调候修正：穷通十干十二月查当月喜忌
           若"调候为急"（冬寒夏燥、身弱用印）与格局用神相左 → 调候优先，标注
        ③ 扶抑校验（由 `ziping-fuyi` 承担）：把格局法结论回填到身强弱上核对是否自洽
           自洽 → 结论稳固；不自洽 → 标注"流派分歧"，双说并陈（见元规则 03）
```

## 三、主从裁决顺序（冲突时谁压谁）

```
优先级（从高到低）：
1. 特殊格（化气/从格/专旺）判定  —— 一旦成立，直接接管，不套正格
2. 调候为急（冬夏 + 身弱用印/寒木火等） —— 格局与调候正面冲突时，调候优先
3. 格局用神（正格范围内的成破、层次） —— 常规断命的主裁决
4. 扶抑校验（身强弱自洽检查） —— 只做校准，不推翻格局结论；不自洽则标注分歧
```

**裁决三原则**：
1. **特殊格优先**：正格法对专旺/从格/化格会系统性误判（真诠自己也声明"从财格、建禄月劫透财不归财格正论"），所以特殊格判定必须在正格之前。
2. **调候不臣服格局**：徐乐吾评注反复以"调候为急"纠正沈孝瞻的表层归类（吴榜眼造用丙不在食印不相碍、而在暖局），这是子平系内部公认的"调候压格局"先例；融合后以徐注口径为准。
3. **扶抑只校验不判案**：真诠明言"（旺衰扶抑）与本书范式冲突时以格局法为准，但须知此为流派之争而非定论"；千里/滴天髓则以身强弱为第一义。二者是"格局 vs 扶抑"的千古之争，本包**不硬裁**：以格局法出主结论，扶抑结论并列呈现，并标注"此二法在此盘上同判/异判"。

## 四、三视角合流的输出格式（面向用户）

对任意八字，最终输出的"用神结论"必须是一张**三栏对照卡**，而非单一用神：

```
┌────────────────────────────────────────────┐
│ 格局用神：X（X格，成/破/混杂，层次：上/中/下） │
│ 调候用神：Y（是否"调候为急"，与格局同向/相左）  │
│ 扶抑用神：Z（身强/弱，该扶/抑，通关字）        │
│ ───────────────────────────────────────── │
│ 主裁决：……（说明以谁为准、分歧在哪、双说并陈）   │
└────────────────────────────────────────────┘
```

## 五、用神唯一性（"用神专一 + 相神辅助"）

- 约言：**用神贵专一而不眩**；用神力不逮时兼取相神；"大富贵之命往往不专恃一神"。
- 真诠：财格"单用财者甚少"，财多为喜神/相神而非用神，须定真正的用神。
- 融合结论：**主用神只定一个**（格局定名后的真用神），其余为相神/喜神，避免"满盘都是用神"的虚断。

## 六、铁律

1. 三视角**必须都跑**，即使结论一致也要写明三者各自是什么（缺一视角即算漏断）。
2. 特殊格判定**先于**一切正格讨论。
3. 冲突处**双说并陈 + 注明流派归属**，不制造"唯一正确"的假象。
4. 每视角结论带出处（书 + 章/块）。
