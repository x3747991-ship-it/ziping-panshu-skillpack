# 元规则 01 · 同名异义对照表

> 十部书最大的隐性障碍，是**同一个词在不同书里意思不同**。"融会贯通"的第一个动作不是合并规则，而是**先把词义钉死**。本表列出六大流派对核心术语的分歧定义，任何子技能使用这些词之前，先按本表确认自己在用哪个含义。

## 一、核心术语六派对照

### 1. 「用神」—— 全书最大的同名异义

| 流派 | 代表书 | 「用神」指什么 | 取用口诀 |
|------|--------|--------------|---------|
| 格局派 | 子平真诠 | 月令定格之神（月令用神） | 「八字用神，专求月令」 |
| 扶抑派 | 滴天髓 / 千里命稿 | 抑强扶弱之字 | 「旺者抑之、弱者扶之」 |
| 病药派 | 神峰通考 | 治病之药 | 「有病方为贵，药到即发」 |
| 调候派 | 穷通宝鉴 | 调候之字（寒暖燥湿补偏） | 「冬夏用神在调候」 |
| 化气派 | 命谱 | 五行消长与合化（不从财官名词取用） | 「凡看八字，先明从化」 |
| 折中派 | 命理约言 | 扶抑之字，且分四层 | 「用神四层：日主/六神/原局/行运」 |

**处理铁律**：用户嘴里说的"用神"若未声明是哪一派，先问清或按上下文判断；**默认以"格局用神"作答并明示**（因为本包以格局法为主轴），同时给出"扶抑/调候"两视角的异同。绝不允许把真诠的"月令用神"和千里的"扶抑用神"混成一个字作战。

### 2. 「喜神 / 忌神」

| 流派 | 定义 |
|------|------|
| 格局派（真诠） | 喜神 = 生助/护佑用神（相神）之字；忌神 = 破格克用神之字 |
| 扶抑派（千里） | 喜 = 生助用神、气顺之字；忌 = 妨害用神、引动失衡之字 |
| 病药派（神峰） | 喜 = 药（制病之字）；忌 = 病（偏枯太过无所谓） |

**注意**：真诠的"喜神"常等于"相神"；神峰的"喜神"就是"药"。三者方向一致但立足点不同，融合后统一表述为 **"喜神 = 助成格局/扶正用神/消除病根之字"**，并注明该结论出自哪派逻辑。

### 3. 「相神」（真诠独有，他书近似"喜神/辅神"）
- 真诠：**相神 = 辅佐用神成格之神**（如财格用食生，食便是相神；官格用印制伤，印是相神）。"伤用甚于伤身，伤相甚于伤用"。
- 约言：近似 **"用神专一而兼取相神"**——用神力不逮时取相神助之。
- 融合表述：相神 = 使格局成立的第二关键字；判断喜忌时，相神受损的严重度按真诠原文分级（伤相 > 伤用 > 伤身）。

### 4. 「通关」（滴天髓核心，他书少见）
- 滴天髓：两神对峙（金木交战、水火相战）之间，取流通之神（如水化金木、木化水火）使战转为生。
- 真诠：无专名，但"财印相碍中隔官星化财生印"即是通关之义。
- 融合：通关 = 对峙两象之间取流通之字；真诠的"中隔化生"、滴天髓的"通关"、神峰的"长药"可互相印证。

### 5. 「调候」（穷通 vs 滴天髓 vs 真诠）
- 穷通宝鉴：调候 = 十干十二月寒暖燥湿补偏（**月令为纲的逐月口诀**）。
- 滴天髓：调候 = 寒暖燥湿四要素，贯穿全柱（寒喜火、暖喜水、燥喜金水、湿喜火土）。
- 真诠：无独立调候章，但徐注反复强调"冬夏用神之义在调候"（吴榜眼造"调候为急用丙"）。
- 融合：调候用神以**穷通十干十二月**为检索主表、**滴天髓寒暖燥湿**为原理补充；真诠格局法与调候冲突时，**调候优先**（见元规则 02）。

### 6. 「体用」
- 滴天髓：**日主为体、月令提纲为用**；用神要"得其所用"，反对机械"身旺喜财官"。
- 真诠：以月令为用、日主为体，与任氏一致但更强调"用神专求月令"。
- 盲派（体用不同义）：盲派"体用"指主位宾位做功，与子平系不同——**本包不采用盲派体用义**，用词时注明。

### 7. 「真神 / 假神」（滴天髓独创）
- 真神：得用、得地、有力、真切的用神；假神：虚浮、无根、混杂、乱局的用神。
- 融合：**真神得用则贵、假神乱局则贱**——这是判格局层次高低的一把标尺（可与真诠"清浊"、约言"清而有神者贵"互证）。

### 8. 「清浊」
- 真诠：清 = 用神相神不杂、成格纯粹；浊 = 混杂相碍、破格。
- 滴天髓：清气/浊气，与真神假神同源。
- 约言：清而有神者贵、浊而无气者贱；"浅而易见者命小，清而难测者命大"。
- 命谱：气禀清浊定贵贱（清高便贵、丰厚便富、衰颓薄浊为贫贱夭）。
- 融合：清浊 = 格局纯粹度与用神真切的统称，四书口径一致，可合并为一套"清浊定层次"标尺。

### 9. 「格局 / 变格 / 外格」
- 真诠：正格八种（财官印食杀伤刃+建禄月劫）+ 杂格还原；"外格"多为俗名，须还原正格论。
- 约言：正格六种（官煞印财食伤）+ 变格六种（从化/一行得气/两神成象/暗冲/暗合）+ 外格辨妄（三十余伪格"无据不取"）。
- 千里：八格（月令本气透→所藏→较量人元），比劫禄刃不取格。
- 滴天髓：八格（但以旺衰体用为纲，不执格名）。
- **融合统一取格链**（三书合流）：① 月支本气透干取格 → ② 本气未透（遭克）用所藏 → ③ 所藏不通用别干势盛者 → ④ 禄刃比劫一律不取格 → ⑤ 疑似从/化/专旺/暗冲暗合先过变格判定。这就是「取格降级链」。

## 二、用词纪律（全局铁律）

1. **写作断语前先声名词义**：凡用"用神/喜神/相神/格局"等分歧词，注明"此处按 XX 派口径：……"。
2. **同名不同义时给双栏对照**，不硬合并、不硬裁掉一派。
3. **出处可追溯**：每句断语尾注（书 + 章/块），出处缺失则标"个人经验，非本书结论"。
4. **不把盲派/旺衰派/神煞派等外来术语混入本包子平术语**，混入时显式标注"外来".
