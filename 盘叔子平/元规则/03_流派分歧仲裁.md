# 元规则 03 · 流派分歧仲裁

> 十书合流后，必然撞上"公说公有理"的正面冲突。本表逐条列出已知分歧、两方立场、以及本包的仲裁结论与表述纪律。**凡遇分歧，给出仲裁结果，同时保留双方立场做"双说并陈"，不做无根据的一方独断。**

## 一、分歧仲裁表

### 分歧 1 · 格局 vs 扶抑（最根本的流派之争）
| 项 | 内容 |
|----|------|
| 正方 | 子平真诠：先问"月令何神成格否"，用神即格局用神，反对先问身强身弱 |
| 反方 | 滴天髓/千里命稿：先定日干强弱，强弱一错后面全错，"论命以日干为主" |
| **仲裁** | 二者是"格局"与"体质"两个层面，可统一为**「先辨体后定格」**：步骤上先定身强弱（扶抑派地基），再定格局用神（格局派主轴）。但**若两法结论相反**（如格局法用官、扶抑法嫌官党煞），以格局法出主结论，扶抑法并列呈现并标注"此盘两法异判，属格局vs扶抑之争"。 |
| 依据 | 真诠自注"以格局法为准，但须知此为流派之争而非定论"；千里自认"八格取法以月令提纲为准"——两书其实共享"月令提纲"这个入口，分歧在"用神落脚点"。 |

### 分歧 2 · 化气是否拘月令
| 项 | 内容 |
|----|------|
| 正方 | 命谱：化气**不拘月令**，"阴阳会合水乳交融气质必起变化"，真伪才以得令权衡 |
| 反方 | 滴天髓/传统：化气须看时令得气得势方能真化 |
| **仲裁** | 化气**成立与否不单看月令**（命谱口径），但**真伪、权力轻重以得令得势权衡**（滴天髓口径）。二说并不矛盾，合为一句：**化气先看是否成象（干合+引化+助化），再看得令与否分真假轻重**。 |
| 依据 | 命谱引《滴天髓》"化得真者只论化，化神还有几般话"自证，可见两书同源不同详略。 |

### 分歧 3 · 神煞 / 纳音 用不用
| 项 | 内容 |
|----|------|
| 反神煞派 | 滴天髓："反神煞、反纳音、反星宫"，以五行生克制化为唯一真理；真诠："神煞无关格局"；约言："神煞多数不取" |
| 神煞派 | 三命通会：神煞纳音大百科（羊刃/七杀/贵人/驿马/华盖/天月德/纳音辉映） |
| **仲裁** | **神煞纳音只取象、不独立成断**：L6 神煞表照供给（三命通会/渊海），但只用在 L8 断事时做辅助取象（如"驿马主奔波""华盖主孤高"），**不得**用神煞"救破格"或"损成格"，不用纳音定富贵。命谱的"纳音助化"仅在化气格内作为助化声势的参考使用。 |
| 依据 | 三书立场一致（真诠/滴天髓/约言），神煞派独树一帜处降为"辅助取象"。 |

### 分歧 4 · 女命口径（明代旧纲 vs 现代）
| 项 | 内容 |
|----|------|
| 旧纲 | 渊海/三命/神峰/滴天髓的女命章：从属地位、"宜柔忌刚""食重孤孀"、以夫为纲 |
| 现代 | 约言明确"陈按男女同理"为总纲；各技能包已把旧纲降为历史标注 |
| **仲裁** | 女命判断**一律按现代职业/财产/独立成就折算**：宫位十神照断，但"克夫""孤孀""相夫教子"类旧纲断语只作历史口径参考，不得作为现代结论硬套。男命运用同理（"妻星"财为妻在现代是伴侣关系非财产关系）。 |
| 依据 | 各技能包"边界"段的自带声明 + 约言"男女同理"陈按。 |

### 分歧 5 · 病药"有病方为贵" vs "中和即富贵"
| 项 | 内容 |
|----|------|
| 正方 | 神峰通考："有病方为贵，无伤不是奇"，纯中和反平庸 |
| 反方 | 命理约言："命贵中和，纯粹中和即富贵"，不可执病药法把中和命断为常人 |
| **仲裁** | 二者针对不同命局，**互补不矛盾**：① 偏枯有救之命——有病有药、药病相当为贵（神峰）；② 四平八稳、财官无损、有生气之命——中和即富贵（约言）；③ 真正下命是"病重无药"或"无格无气"。融合后**两把尺子并列**：先看"有病无病"，有病则用药断贵、无病则用中和断贵，不强行统一。 |
| 依据 | 约言原文已点破："病药之法可用而不必过拘"；神峰原文"药病相当为上格"——神峰自己也没否定中和命，是否定"无病则奇"的误解。 |

### 分歧 6 · 犯太岁是否必凶
| 项 | 内容 |
|----|------|
| 民俗 | "犯太岁必大凶"（流年冲克生年/日主） |
| 理法 | 三命通会："岁运并临唯羊刃七杀为凶，财官印反吉"；约言："犯岁合岁在本书多不凶反吉（偏财/财官），看日主气势能否任受" |
| **仲裁** | **推翻"犯太岁必凶"**：并临、犯岁、伏吟反吟的吉凶**只看所并所犯之神与命局用神的生克关系**，不看形式本身。民俗说法在断语中显式纠正并给理法依据。 |
| 依据 | 三命通会卷二、约言"犯岁之辨"专论。 |

### 分歧 7 · "财官入库不冲不发" vs "冲反拔根"
| 项 | 内容 |
|----|------|
| 俗说 | 财官入库必须逢冲方能发（冲库开库） |
| 真诠 | "财官入库不冲不发是俗书谬说"；透干为用者逢冲反拔根，不冲而透反贵 |
| **仲裁** | 以真诠为准：**库藏以透干为取用标准，不以冲库为取用标准**；"冲库开库"仅在某些专论（如辰戌丑未四库全）作辅助，不作通用规则。 |
| 依据 | 子平真诠论杂气；约言"投库必冲是俗书之谬"同证。 |

### 分歧 8 · 十干阴阳同生同死 vs 分生死
| 项 | 内容 |
|----|------|
| 一方 | 以阴阳之干分长生（阳顺阴逆、甲长生亥乙长生午） |
| 约言 | "阴阳同生同死"（甲亥生乙亦亥生），且"阳长生有力、阴长生不甚有力" |
| **仲裁** | 以约言口径为准（阴阳同生同死 + 阴长生无力）；若遇到按"阴干逆排长生"论旺衰的旧法，显式标注为"旧法阴阳分生死，本包从约言同生同死"。 |
| 依据 | 命理约言"十干生旺墓（阴阳同生同死）"。 |

### 分歧 9 · 从格月令限定
| 项 | 内容 |
|----|------|
| 穷通宝鉴 | 三月甲木"辰月木气将竭可从"，未月不可从——从格随月令节气有空 |
| 传统 | 从格只看日主无根否，不深究月令 |
| **仲裁** | 从格判定**先看日主是否无根无气、独神是否满局**（约言"满官从官满财从财"），再**参以月令节气定可不可从**（穷通）：辰月木竭可从、未月木尚有气不可从等。两说合并为"从格要件 = 弃命无根 + 独神势成 + 顺月令盛衰"。 |
| 依据 | 穷通宝鉴三月甲木条；命理约言从局法。 |

### 分歧 10 · 禄刃比劫是否取格
| 项 | 内容 |
|----|------|
| 一致 | 真诠、千里、约言三家**一致**：禄刃比劫不取格，只为日主之助；建禄月劫另立（真诠归杂格、千里月劫不取格） |
| **仲裁** | 无分歧，统一口径即可：**比劫禄刃一律不取格**，建禄/月劫作"杂格/月劫格"专论（真诠口径）。 |

## 二、仲裁总原则（面向所有未来新遇分歧）

1. **格局法为体、扶抑法为用、调候法为调、病药法为诊**——四法角色固定，冲突按此定位裁决。
2. **俗说/民俗让位于理法**（犯太岁必凶、冲库开库、投库必冲等一律纠正）。
3. **历史口径让位于现代**（女命、小儿关煞、寿夭等旧纲降级为标注）。
4. **两法同源处寻共同入口**（如"月令提纲"是格局派与扶抑派共同入口）再分主从。
5. **无法裁决时，双说并陈 + 标注流派，绝不伪造唯一答案。**
6. 每一条仲裁都**带出处**，保留双方原文立场。
